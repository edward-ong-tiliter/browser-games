▼ 🎨 Drawing Games

Skribbl.io
Drawing
👥 Up to 20 players 💰 Free 🔒 Private room ✅ Invite link 📱 Mobile ✅ 📝 Account needed ❌
Pictionary online. One draws, others guess in chat. Custom word lists, private rooms, moderation tools (kick/ban/votekick). Game length configurable 5–30 min. 25 languages.

✅ Pros

  • Dead simple, zero install
  • Free forever, no account
  • Custom word lists
  • Up to 20 in custom rooms

⚠️ Cons

  • No built-in voice chat
  • Basic drawing tools
  • Ads
  • User-drawn content = not guaranteed SFW
🌐 Play Skribbl.io
Gartic Phone
Drawing / Telephone
👥 4–30 players 💰 Free 🔒 Private room ✅ Room code/QR 📱 Mobile ✅ 📝 Account needed ❌
Telephone game meets Pictionary. Write sentence → next draws → next guesses → chain. Parallel chains (everyone starts at once). Modes: Normal, Knock-Off, Animation, Icebreaker, Exquisite Corpse, Co-op. Save as GIF.

✅ Pros

  • Free, no install, phone+desktop
  • Big groups (4–30)
  • Turn-parallel = no waiting
  • Deep mode list, 40+ languages
  • 4.8★ on Google Play

⚠️ Cons

  • No voice chat (pair Discord/Zoom)
  • Mobile drawing clunky
  • User-generated prompts = not guaranteed SFW
🌐 Play Gartic Phone
Drawize
Drawing
👥 Up to 100 players 💰 Free (ads) / Ad-free from $9 🔒 Private room ✅ Room code/link 📱 Mobile ✅ 📝 Account needed ❌
Polished Pictionary with Teams Mode (co-op groups), Spectator Mode (streaming), Drawize Phone (telephone), CopyCatAI. Class/event passes available for large groups.

✅ Pros

  • Up to 100 players
  • Teams + Spectator modes
  • Classroom/teacher tools

⚠️ Cons

  • Ads on free tier
  • Premium-gated features
  • Less known than Skribbl
🌐 Play Drawize

▼ 🗣️ Word Games

JKLM.FUN
Word / Trivia
👥 BombParty 2–16 • PopSauce 2–100 💰 Free (donation-funded) 🔒 Private room ✅ Room code 📱 Mobile ✅ 📝 Account needed ❌
Three games: BombParty — type words containing given syllable before bomb explodes. PopSauce — trivia/pop-culture quiz (filter by theme + difficulty). Master of the Grid — trivia game show (up to 83 players). Has Discord integration, BirdBot (1v1 bot).

✅ Pros

  • 100% free, no account
  • Easy private rooms
  • BombParty up to 16, PopSauce up to 100
  • Active Discord community

⚠️ Cons

  • BombParty rewards big vocab
  • Only word + trivia (no drawing/music)
  • Dictionary secret + strict
🌐 Play JKLM.FUN 📖 FAQ
Codenames Online
Word / Party
👥 4–8 players 💰 Free (official CGE, no ads) 🔒 Private room ✅ Room URL 📱 Mobile ✅ 📝 Account needed ❌
Official Czech Games Edition browser version. Two teams, Spymaster gives 1-word clue, operatives guess tiles. Hit assassin = instant loss. Daily puzzle mode. 2016 Spiel des Jahres winner.

✅ Pros

  • Officially licensed, free, no ads
  • Perfect social/party game
  • High replay value
  • Daily puzzle mode

⚠️ Cons

  • Need external voice chat
  • Downtime between turns
  • Web wordlist smaller than physical deck
🌐 Play Codenames 🔄 Alt: Kodenames.io (more features)
Wavelength Online
Word / Spectrum
👥 2–12 players 💰 Free forever 🔒 Private room ✅ Room code 📱 Mobile ✅ 📝 Account needed ❌ (optional for stats)
Psychic sees hidden target on spectrum (Hot↔Cold), gives 1-word clue. Others guess where target lands. 3 modes: One Psychic, One Guesser, Teams. Custom prompts. ⚠️ Unofficial fan recreation (not CMYK Games).

✅ Pros

  • Free, no account, no download
  • Private lobby + public games
  • 3 game modes, custom prompts
  • Local pass-and-play

⚠️ Cons

  • Unofficial clone
  • Digital dial not same as physical board
🌐 Play Wavelength Online
ScattergoriesOnline
Word / Categories
👥 10+ players 💰 Free 🔒 Private room ✅ Invite link 📱 Mobile ✅ 📝 Account needed Free login for some features
Classic Scattergories. Get letter + categories, write unique answers before timer. Custom categories, skip letters, Game Master mode, AI bots. 25M+ games played, 40 languages.

✅ Pros

  • Closest thing to real online Scattergories
  • Play-by-link perfect over Zoom/Discord
  • Customizable rules

⚠️ Cons

  • Ugly site
  • Some features need login
🌐 Play ScattergoriesOnline
StopotS
Word / Categories
👥 Large rooms 💰 Free (ad-supported) 🔒 Private room ✅ Room code 📱 Mobile ✅ (10M+ downloads, 4.2★)
Fast Scattergories-style word race. 20 categories per round, type answers fast. Real-time competitive. From the same devs as Gartic Phone (Onrizon).
🌐 Play StopotS
LetterJam
Word / Co-op
👥 2–6 players 💰 Free 🔒 Private room ✅ Room link
Cooperative word game from Czech Games Edition (same as Codenames). Work together to find the secret word.
🌐 Play LetterJam

▼ 🕵️ Social Deduction Games

Spyfall Online
Social Deduction
👥 3–8 players 💰 Free (MIT open source) 🔒 Private room ✅ Room code 📱 Mobile ✅ 📝 Account needed ❌
One spy, others get location + role. Spy doesn't know location. Players ask questions, expose spy. Includes Spyfall 1 + 2 location packs + "all players are spies" mode. 30+ languages. Default timer 8 min.

✅ Pros

  • Free, open source, modern
  • Private room codes + multiple location packs
  • Mobile-friendly, 30+ languages

⚠️ Cons

  • Needs friends (no random match)
  • Not official license
🌐 Play Spyfall 🔄 Alt: SpyfallX
Betrayal.io
Social Deduction
👥 6–12 players 💰 Free 🖥️ Browser ✅
"Inspired by Werewolf, Town of Salem, Among Us." Mystery game where players work together and one betrays. Pure browser, fast games.
🌐 Play Betrayal.io
Epic Mafia
Social Deduction / Mafia
👥 9–16 players (varies) 💰 Free 🖥️ Browser ✅
Online expansion of classic Mafia. 220 unique roles, thousands of table setups, 2M+ games played. Mini-games: Liars Dice, Tiramisu, Ghost. Trophies/community respect system.

✅ Pros

  • Massive role depth
  • Competitive Mafia done right

⚠️ Cons

  • Text-based, punishing learning curve
  • Not casual-friendly
🌐 Play Epic Mafia

FPS / Action
👥 Host sets limit (private rooms) 💰 Free (ad-supported) 🔒 Private room ✅ Invite link + code 📱 Mobile ✅ 📝 Account needed ❌
Cartoony egg FPS. Fast, silly, easy for mixed-skill friend groups. 50+ maps, 4 modes (FFA, Teams, King of the Coop, Capsula). Create private room → share link → play. Mirror: shellgame.me.

✅ Pros

  • 50+ maps, 4 modes
